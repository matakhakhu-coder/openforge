# Social icons

Single SVG files copied from Bootstrap Icons 1.13.2 (MIT licence), taken from the osint-platform repo.
Licence: https://github.com/twbs/icons/blob/main/LICENSE (keep this link on file).
The logos are trademarks of their owners. They are used only to link to our own profiles.

To add a platform: add its name to SocialPlatform in src/config.ts, add one line to the social list there, and drop its SVG here, named after the platform.
